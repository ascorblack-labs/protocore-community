# Ядро Protocore — Документация

`protocore` — это **чистое ядро** агентной среды выполнения Protocore: библиотека
на Python 3.12+, состоящая из **контрактов** (Protocol-классы и типизированные
модели) и **protocol-first ReAct-среды выполнения**, которая ведёт по одному ходу
агента за раз. Это **универсальное мультитенантное** ядро продукта без единого
импорта «вверх» — у него нет ни драйвера базы данных, ни HTTP-эндпоинтов, ни
логики развёртывания; всё, что обращено наружу, оформлено как `Protocol`, который
реализует слой хоста. Точки входа среды выполнения — `QueryEngine` (владелец
состояния отдельного запуска) и `query()` (**синхронная** функция, которая
сбрасывает состояние хода и возвращает асинхронный итератор `TurnEvent`); оба
импортируются из `protocore.runtime.*`.

## Порядок чтения

Новый инженер или агент может прочитать эти документы подряд, в таком порядке:

1. **[Начало работы](getting-started.md)** — установка через `uv`, затем
   минимальная работоспособная форма: собрать `QueryEngine` с внедрёнными
   адаптерами и стримить ход через `query()`.
2. **[Архитектура](architecture.md)** — подробный справочник: слоистая структура,
   поток данных одного хода, перечень технологий и обзор по подсистемам.
3. **[Контракты](contracts.md)** — граница: интерфейсные `Protocol`-классы,
   которые реализует слой хоста, и система типов ядра.
4. **[Инструменты](tools.md)** — лаконичная поверхность глаголов, декоратор
   `@tool`, конвейер диспетчеризации, шлюз разрешений и предусловия инструментов.
5. **[Константы среды выполнения](runtime-constants.md)** — как каждое
   настраиваемое значение проходит через замороженный снимок `RuntimeConstants` и
   как прочитать значение по умолчанию.
6. **[Расширение](extending.md)** — выбор шва: `Protocol`, хук, переключатель RC
   или секция системного промпта — плюс правила, которые нельзя нарушать.
7. **[Тестирование](testing.md)** — как запускать тесты, линтер, проверку типов и
   сканирование безопасности и что именно проверяет тест-страж границы импортов.
8. **[Глоссарий](glossary.md)** — краткие определения терминов, используемых во
   всей документации.

## Двуязычная документация

Это русское зеркало дерева `docs/`. Каноническим источником является
**английская** версия, которая находится в [`../index.md`](../index.md) с
однозначным соответствием набора файлов и заголовков. Любое изменение сначала
правит английский файл, затем в том же наборе правок обновляет его русский
аналог; каждый русский файл фиксирует путь к источнику и коммит, из которого он
был переведён. Два проектных README следуют той же паре: русский
[`../../README.md`](../../README.md) — основной, а английский
[`../../README.en.md`](../../README.en.md) — его зеркало.
